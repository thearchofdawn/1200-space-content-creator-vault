# Preview Assets

Upload the 10 preview files for the landing page in this folder using these names:

- `preview-01.jpg` / `.jpeg` / `.png` / `.webp` / `.mp4` / `.webm` / `.mov`
- `preview-02` through `preview-10` using the same naming pattern

The landing page automatically checks image and video formats and displays the matching file in the **See What's Inside** section.

For video previews, MP4 is recommended for broad browser compatibility. Videos are displayed muted, autoplaying, looping, and inline.
